# Developing the new www.qmind.ca website for Canada's largest undergraduate AI club.

## How to contribute:

Clone the repository
```
git clone git@github.com:stefpi/QMIND2024.git
cd QMIND2024
npm install
```

Create your own branch
```
git checkout -b <your branches name>
```

After you have made your changes
```
git add .
git commit -m <a good commit message describing what you did. you can follow this guide https://www.conventionalcommits.org/en/v1.0.0/>
git push
```

Then make a pull/merge request from your branch to main and assign @stefpi as a reviewer!

## Technologies
- Next.js
- Tailwind
- SASS
