# QMIND.ca
The official website for QMIND, Canada's largest undergraduate AI organization. Only Operations Executives should have access to this repo. 

## tech stack
- Next.js
- Tailwind
- Supabase
- Netlify

## setup 
```
# Clone the repo
git clone https://github.com/QMIND-ORG-NAME/QMIND2026.git
cd QMIND2026

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Fill in Supabase credentials in .env.local

# Run the dev server
npm run dev
```
## contributing 
All changes go through pull requests. Nothing is pushed directly to main (anymore...). 
1. create a new branch: ```git checkout -b your-feature-name```
2. make your changes and commit them
3. push your branch and open a pull request.
